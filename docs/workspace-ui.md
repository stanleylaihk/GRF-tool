# GRF 工作區 1.4.0

介面分成兩層：外層左側係資料夾／來源清單，右側係內容區；內容區上方係工具列及搜尋，下方再分成左側檔案清單、右側預覽。兩條分隔線可以拖拉調整闊度。主視窗唔顯示額外標題列或重複封包名稱，名稱只顯示喺左側來源清單。獨立檔案以所在資料夾作來源；GRF 草稿仍然保留，可以喺左欄切返。

修改先放喺待儲存清單。重新命名、取代及刪除同一資源只佔一項，支援單項復原、上一步及全部復原。另存後先建立新 GRF，唔會覆寫原 GRF 或合併來源。解壓使用草稿目前嘅內容，已刪除資源唔會輸出；遇到覆蓋衝突會停止。

內容搜尋按 Enter 執行，範圍係整個目前來源，唔受資料夾篩選限制。只搜尋已知文字格式，每檔上限 16 MiB；二進位及過大檔案會跳過並顯示數量。命中摘要提供行號及數量，預覽可跳到上／下一個命中。文字編碼沿用自動偵測或使用者選擇。

RSM 預設 Wireframe，可切換 Textured；支援版本 1.1–1.4 靜態模型。RSW 支援 1.2–2.1，組合 GND 地形、RSM 模型及貼圖，保留物件旋轉及縮放。支援相機旋轉及縮放；缺失資源會列出。唔重現遊戲水面、特效、完整光照或動畫。資源由目前草稿或本機 data 根目錄解析，唔會跟隨任意外部路徑。

組合預覽最多讀取 192 MiB 相依資源，每個相依資源上限 32 MiB，地形上限 262,144 格，獨立模型合共上限 2,000,000 三角面。超出限制會列入缺失或載入報告。

GR2 v6 提供 Wireframe／Textured，預設線框，支援內嵌 RAW／IGC 貼圖及靜態第一幀姿勢。動作檔會喺目前來源或本機 data 根目錄，配對唯一嘅 3dmob 基礎模型；缺少配套時會提示，唔會假裝顯示完整角色。未提供動畫播放；其他 Granny 版本或壓縮方式可能不支援。Info 保留原始區段資料。其他未知或無法解析嘅資源會提供 Info／Strings／Hex；Hex 顯示首 64 KiB，超過 64 MiB 嘅資源只顯示摘要。專用預覽失敗唔會阻止解壓原始檔案。

驗證包含草稿復原、衝突、另存及安全解壓、文字搜尋與中文命中、合成場景貼圖及轉換，以及真實 data.grf 嘅 Prontera 場景（65 個模型、221 個貼圖，冇缺失相依資源）。另以實際介面檢查獨立 RSM 三欄、搜尋、取代、重新命名、刪除與復原、Credits 及另存副本。

工作區工具列、側欄導覽及預覽按鈕喺滑鼠移入時以藍色文字／圖示提示，停用按鈕保持灰淡。搜尋提示會按檔名、內容或兩者模式切換。SPR／ACT 縮放控制放喺預覽標題右側，提供減少、百分比重設及增加；按百分比回復 100%。動作／音效統計有獨立間距，底部唔再重複顯示檔名及大小。

頂部工具列嘅空白位置亦可拖動視窗；選單同一般按鈕共用單層 hover，唔會喺選單標籤再疊背景。

## 介面語言

Settings → Interface Language 支援英文、繁體中文、日文及韓文，即時切換並保留選擇。翻譯涵蓋工作區、設定、預覽控制、右鍵選單及操作對話框。檔名、資源內容、JSON、授權原文同未識別嘅底層診斷保留原文；文字解碼選擇獨立於介面語言。切換語言唔會重新開啟 GRF 或清除待儲存草稿。
